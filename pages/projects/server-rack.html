Server Rack Component Detector

I along with a team of 4 worked with AV-Worx, an Audio Visual Inegration company, to develop a mobile application for server rack component detection, for identifying and annotating server rack components from images accurately, streamlining inventory management processes of the company. I was the machine learning engineer and implemented convolutional neural networks for image classification and object detection, which then was used to train the model on a dataset of 5000+ images of server rack components, achieving a 70% accuracy rate in component identification over a tested selection of 1000+ images. It was then ported to a IOS application for production use, and is currently being used by the company to assist in inventory management and component identification.
